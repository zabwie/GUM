and the decoder. Matched every H2D weight-copy size in schedule order to
the target-verification NVTX ranges in the existing Nsight trace.

Compression sampled 16 rows per cold chunk (or the entire smaller chunk)
alternating between the first and third quartile. Whole-chunk tests
sampled two chunks at thirds of file order per tier and tensor role
for ffn_gate, ffn_up, ffn_down, attn_qkv, attn_q, and ssm_out. Each zstd
level 3 chunk was independently byte-round-tripped. The planar layout
separates Q4 nibbles from the two bytes of each scale. It has no GPU
decompression timing. Some full cold samples overlap the 16-row samples.

Speculative row counts use one known input plus all proposed rows per
pass. Decode token counts exclude the first token obtained in prefill.
E152 uses the known dense continuation as an oracle, so its byte/token
ratio measures the effect of longer exact continuations in isolation.
